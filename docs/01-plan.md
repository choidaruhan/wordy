# 01. 제품 기획

> **Wordy** — 단어를 외우는 게 아니라, 기억하게 만든다.
> 매일 조금씩, 오래 남는 영어 단어 학습.

| 항목 | 내용 |
|---|---|
| 프로젝트명 | Wordy (가칭) |
| 서비스 유형 | 영어 단어 학습 PWA |
| 플랫폼 | 반응형 웹 + PWA |
| 주요 사용자 | 영어 입문자·초보자 |
| 핵심 콘텐츠 | 검수된 기초 단어 1,000개 |
| 학습 엔진 | FSRS 간격 반복 + 인출 연습 |
| 개발 목표 | 개인 프로젝트 → 실제 사용 가능한 서비스 |

> 인프라 식별자(`wrangler.jsonc`의 `english-learning`, D1 이름)는 그대로 둔다.

## 한 줄 정의

하루 10분, 오늘 볼 카드만큼만. 다 하면 앱이 알아서 다음 복습일을 잡아준다.

## 타겟

| 구분 | 설명 | 우선순위 |
|---|---|---|
| 영어 입문자 | 중학교 단어부터 다시 시작 | **1차** |
| 영어 초보자 | 외워도 금방 잊어버림 | **1차** |
| 직장인 | 하루 10분, 짧고 확실하게 | 2차 |
| 학생 | 시험 대비 체계적 암기 | 2차 |

초기에는 입문자·초보자에 집중한다. 상급자는 카드 유형이 부족하게 느낄 수 있다.

## 사용자 문제

1. **뭘 외워야 할지 모른다** — 매일 무엇을 볼지 고민하는 데서 이탈한다.
2. **외운 걸 또 외운다** — 아는 단어에 시간을 쓰고, 까먹은 단어는 방치된다.
3. **앱이 무겁다** — 광고, 로딩, 회원가입 유도, 결제 팝업.
4. **뜻은 아는데 못 쓴다** — 영→한만 반복하면 "보면 아는" 상태에서 멈춘다.

## 핵심 가치

| 가치 | 구현 방식 |
|---|---|
| **결정 피로 제거** | 앱이 "오늘의 큐"를 만든다. 사용자는 버튼만 누른다. |
| **효율** | FSRS 간격 반복. 아는 단어는 안 물어본다. |
| **속도** | 서버 렌더 HTML, 클라이언트 JS ~52KB, 첫 응답 10ms대 |
| **소유권** | 단어장 CSV 내보내기/가져오기 무료. 락인 없음. |

## 차별점

| 경쟁 | 우리 |
|---|---|
| Anki — 강력하지만 복잡하고 무겁다 | 웹/PWA. 설치 없이 열리고 가볍다 |
| Quizlet/WordUp — 광고·구독 유도 | 광고 없음, 핵심 기능 전부 무료 |
| 직접 만든 엑셀 — 스케줄링 없음 | 자동 복습. 잊을 때쯤 다시 |
| 대부분의 단어 앱 — 영→한에서 멈춤 | **한→영 타이핑까지 간다** |

**핵심 주장**: 영→한은 입구, 한→영은 출구다.
출구가 없으면 시험장에서 쓸 수 있는 상태까지 데려가지 못한다.

## 기능 영역과 현재 커버리지

| 영역 | 내용 | 상태 |
|---|---|---|
| Dashboard | 오늘의 학습, 진행률, 외운 단어 | ✅ |

| Learning | 신규 소개, 영→한 카드, 발음 | ✅ |
| Review | FSRS 큐, 복습, 어려운 단어 격리 | ✅ |
| Quiz | 객관식 4지선다 (학습 일정과 분리) | ✅ |
| Statistics | 기간별 학습량, 정답률, 연속일 | ✅ |
| Content | 기본 1,000 + 기능어 100 | ✅ |
| User | 목표, 알림, 내보내기 | ✅ (알림 제외) |

## 콘텐츠 전략

### 1단계 — 기본 1,000개 (완료)

`public/seeds/basic-1000.csv`

- 명사 350 · 동사 291 · 형용사 205 · 부사 110 · 구동사 44
- 기능어(the, of, and…)는 의도적으로 제외 — 문법이지 암기 대상이 아니다
- 검수: `npm run check:seed` (중복·빈 필드·예문 포함 여부)

> 참고: `~/Downloads/basic-1000-reviewed-v2.csv` 는 현재 시드와 **내용 차이가 없다**.
> BOM과 헤더 따옴표만 다르다. 그대로 쓰면 된다.

### 2단계 — 기능어 100개 (완료)

현재 목록에서 빠진 실제 약점. 문장 이해에 필요하다.

`public/seeds/function-100.csv`

| 분류 | 예 | 수 |
|---|---|---|
| 관사·한정사 | a, an, the, this, some, any | 19 |
| 대명사 | I, you, he, they, it, we | 25 |
| 전치사 | in, on, at, for, with, about | 30 |
| 접속사 | and, but, because, although, while | 15 |
| 조동사 | can, will, should, must, may | 11 |

- 별도 단어장 `기능어 100` 으로 제공
- 기본 1,000개와 **단어 중복 0건**
- 개별 단어보다 **문장 속 예문** 중심
- 기능어는 승급 대상에서 제외한다 (아래 참고)

> **왜 한→영 카드를 만들지 않는가**
> `"~안에"` → `in`, `"그"` → `the` 처럼 답이 하나로 정해지지 않는다.
> 기능어는 문맥(cloze)으로만 검증해야 하므로 `pos` 가 `det/pron/prep/conj/modal` 인 단어는
> `recall` 카드를 생성하지 않는다. cloze 카드는 M3.5에서 붙인다.

### 3단계 — 난이도 (선택)

CEFR A1~C2를 `words.level` 로 추가한다.
**임의로 확정하지 않고 검수 후 등록한다.** 하나의 단어가 여러 레벨에 속할 수 있다.
